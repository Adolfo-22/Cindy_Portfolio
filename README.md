# My Learning Journey

A dependency-free static e-portfolio for ISED 2 – Seminar in Professional Education.

## Customize

1. Open `js/data.js` and replace bracketed placeholders with authentic information.
2. Add real scores only when you have verified them. Scores must be numeric and totals must be greater than zero.
3. Place evidence files in `assets/evidence/profed/`, `midterm/`, `final/`, or `online/`, then set the matching relative path in `data.js`.
4. Replace `assets/images/profile-placeholder.svg` with a suitable profile image if desired.
5. Replace bracketed reflection passages with your own first-person writing.
6. Redact student numbers, signatures, and other private information before public deployment.

Checklist states are stored locally in the browser only. This site does not upload files or create a database.

## Run locally

Open `index.html` directly, or serve the folder with any static server. No Node.js or build step is required.

## Deploy

Upload the project to GitHub Pages, Netlify, or Vercel as a static site. Keep relative paths intact.
